## 5. Scenario-Based Demo & Practice Questions

### Question 1
Which Oracle APEX page component provides an Excel-like editable grid interface allowing users to edit multiple rows and save batch changes declaratively?

A) Interactive Grid
B) Classic Report
C) Static Content Region
D) Faceted Search Region

- **Correct Answer**: `A) Interactive Grid`  
- **Technical Explanation**: The Interactive Grid component provides full rich-client editable grid capabilities, including inline cell editing, sorting, filtering, charting, and bulk data saving.

---

### Question 2
In Oracle APEX, what security feature prevents users from altering URL query parameters to view or manipulate data belonging to other records (URL tampering)?

A) Session State Protection (SSP)
B) Database Vault factor
C) Table TDE encryption
D) Virtual Private Network tunnel

- **Correct Answer**: `A) Session State Protection (SSP)`  
- **Technical Explanation**: Session State Protection (SSP) prevents URL tampering by verifying cryptographic checksums on page arguments and request items passed in URLs.
